# Confiles

## Installation

Clone the repository:
```bash
git clone https://github.com/RaabPhilip/Confiles.git
```

Set up Stow:
```bash
sudo pacman -S stow
```

Init Stow:
```bash
cd Confiles
stow -t ~ .
```
